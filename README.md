# EV Battery Pack and BMS Simulation

A MATLAB/Simulink project modeling a simplified EV battery pack and battery-management system.

## Planned Features

- 96S20P battery-pack model
- Drive-cycle current demand
- State-of-charge estimation
- Voltage sag from internal resistance
- Simplified thermal model
- BMS warning, derating, and shutdown logic

## Status

Project setup in progress.
